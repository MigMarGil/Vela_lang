# Vela launch plan

## 1. Make the first impression clear
- Keep the README short and honest: this is an experimental language with working compiler pieces, not a fake "vision".
- Add a landing page under docs/index.html so people can understand the project quickly.

## 2. Publish the right content
Use these channels in order:

1. GitHub repository page
   - Make the README visual and concise.
   - Add screenshots or a short demo GIF if possible.
   - Pin a "Hello world" example and the install command.

2. X / Twitter
   - Share one concrete milestone per week.
   - Example: "Built a working CLI for Vela that compiles a simple program to LLVM IR."

3. Reddit: r/programming, r/learnprogramming, r/compilers
   - Post only when there is a tangible improvement or demo.
   - Avoid announcing a language before it has a crisp demo.

4. Hacker News
   - It only works when the project has a clear value proposition and a real demo.
   - A polished README and a short video matter more than hype.

5. LinkedIn
   - Better used as a portfolio signal than as a launch platform.
   - Share the engineering story: why you built it, what works, what is next.

## 3. What to publish this week
- A short video of the CLI running hello.vela
- A screenshot of the compiler pipeline or generated LLVM IR
- A post that says: "I built a tiny language in Python that can parse, type-check, and compile a simple program to LLVM IR."

## 4. What will make it memorable
- A clear, unusual feature that is actually implemented
- A real working demo
- A consistent weekly rhythm of progress

## 5. Suggested positioning
Position Vela as:
- a compact compiler experiment
- a teaching language for compiler concepts
- a personal project with a real pipeline from source to executable
