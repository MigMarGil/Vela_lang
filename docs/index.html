Vela

A compact programming language born from a simple ambition: build something that could one day be used by a community, tested against real benchmarks, and taken seriously as a systems-level tool.

View repository Try it locally

Why Vela exists

The project started as an ambitious personal challenge: create a language that could be judged by performance, clarity, and usefulness rather than by hype alone. Benchmarks matter because they turn a dream into something measurable.

What it offers

  • Readable syntax with type inference
  • LLVM-based compilation pipeline
  • Examples for algorithms, scripts, and control flow
  • Simple CLI for running and checking programs

Quick start

git clone https://github.com/MigMarGil/Vela_lang.git
cd Vela_lang
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
vela run examples/basic/hello.vela
